# Ser ingeniero: ciencias, sistemas y desafíos del siglo XXI

Presentación web interactiva de 18 capítulos.

Para verla localmente desde esta carpeta:

```bash
python3 -m http.server 4174
```

Luego abre `http://127.0.0.1:4174`.

Controles: flechas, Page Up/Page Down, rueda del mouse, gesto vertical en pantallas táctiles y botón de vista general.
